## 文档维护规则

- 新专题使用 `NNN_中文标题.md` 稳定文件名；
- 同一主题的方案、实现、审查和修复复用同一个编号；
- 新文档先写入 `临时/`，用户明确认可后再移入正式分类；
- 方案和审查类文档记录 `未开始 / 进行中 / 已完成`，状态必须符合真实执行情况；
- 功能和经验文档不记录执行状态；
- 新增、移动、归档或改变执行状态时同步更新本索引；
- 项目内链接使用相对路径。
